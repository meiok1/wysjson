# 部署说明 — JSONOKOK (indexMonaco.html)

本文说明如何把 `indexMonaco.html` 部署到静态网站服务器（Nginx / IIS / Apache / S3 / 任意静态托管）。

目标：把部署目录 `部署方式/网页部署` 下的所有内容拷贝到远程服务器的静态根目录（例如 `/var/www/html/jsonokok`）。

重要依赖（不要遗漏）

- `indexMonaco.html` — 主页面（已修改为本地加载 Monaco）。
- `node_modules/monaco-editor/min/**` — 必须包含 `min/vs` 目录（Monaco 编辑器的运行时文件与 worker）。
  - 注意：页面使用相对路径 `./node_modules/monaco-editor/min/vs/loader.js` 加载 Monaco，因此需要在部署包中保留相同的相对路径。
- `src/pic/kaoPuGuiWeChat.jpg` — 作者微信二维码（用于“联系作者”弹窗）。
- `src/pic/zanShangMa.jpg` — 打赏二维码（用于“微信赞赏”弹窗）。

简要清单（以 `部署方式/网页部署` 为根）

- indexMonaco.html
- node_modules/monaco-editor/min/\*\*
- src/pic/kaoPuGuiWeChat.jpg
- src/pic/zanShangMa.jpg

（可选）如需保留仓库元数据或便于二次维护，可同时复制 `package.json`、`README.md` 等，但不是运行必需项。

为什么需要 `monaco-editor` 本地部署？

- `indexMonaco.html` 通过 `./node_modules/monaco-editor/min/vs/loader.js` 加载 Monaco。Monaco 会在运行时加载额外的 worker 脚本（`vs/base/worker/workerMain.js` 等），这些文件必须和 `loader.js` 同源可访问，否则编辑器无法正常工作。
- 技术上你可以改为从 CDN 加载 Monaco（例如 `https://unpkg.com/monaco-editor@<ver>/min/vs/loader.js`），但需要额外配置 worker 路径或代理以避免跨域/worker 加载问题。建议直接把 `min` 目录一并部署到服务器以确保兼容性。

部署步骤（本地准备）

1. 在本地仓库根目录（含 `package.json` 的目录，即 `D:\WysProgrammingTest\wysJSON`）运行：

```powershell
npm install --no-audit --no-fund
```

这将安装 `monaco-editor` 到 `node_modules`（若已安装可跳过）。

2. 将以下文件/目录复制到 `部署方式/网页部署`：
   - `indexMonaco.html`
   - `node_modules/monaco-editor/min/`（全量）
   - `src/pic/kaoPuGuiWeChat.jpg`
   - `src/pic/zanShangMa.jpg`

我已在仓库内提供了一个辅助脚本 `部署方式/prepare_deploy.ps1`，用于自动化复制这些文件（见下）。你也可以手动复制。

在 Linux/macOS：可使用 `rsync` 或 `scp` 将整个 `部署方式/网页部署` 目录上传到远端（示例）：

```bash
# 把本地部署目录上传到远程服务器 /var/www/html/jsonokok
scp -r D:/WysProgrammingTest/wysJSON/部署方式/网页部署/* user@your-server:/var/www/html/jsonokok/
# 或使用 rsync
rsync -av --progress "D:/WysProgrammingTest/wysJSON/部署方式/网页部署/" user@your-server:/var/www/html/jsonokok/
```

在 Windows Server（IIS）上：将 `部署方式/网页部署` 内容复制到 IIS 的站点目录或虚拟目录下。

Nginx（示例配置）

```
server {
    listen 80;
    server_name example.com;
    root /var/www/html/jsonokok; # 指向 indexMonaco.html 所在目录

    location / {
        try_files $uri $uri/ =404;
    }
}
```

常见问题 & 排查

- Monaco 无法加载或编辑器空白：
  - 打开浏览器开发者控制台查看网络请求，确认 `./node_modules/monaco-editor/min/vs/loader.js` 和 `vs/*` 下的脚本都返回 200。
  - 如果看到关于 worker 的跨域或 404 错误，说明 `min/vs` 路径没有正确部署或被 CDN 跨域阻止。建议本地部署 `min` 目录。

- 二维码图片无法显示：检查 `src/pic/` 子目录是否存在并包含上面两个 JPG 文件，且 `indexMonaco.html` 与 `src` 文件夹保持相对位置关系（页面中使用 `./src/pic/...` 引用）。

- 如果你希望把 Monaco 放到不同的路径（例如 `/static/monaco/`），请在 `indexMonaco.html` 中修改加载路径：

```js
// 修改 monacoBase 指向静态目录，例如 '/static/monaco/min'
window.MonacoEnvironment = window.MonacoEnvironment || {};
window.MonacoEnvironment.getWorkerUrl = () => {
  const monacoBase = "/static/monaco/min";
  const workerCode = `self.MonacoEnvironment = { baseUrl: '${monacoBase}/' }; importScripts('${monacoBase}/vs/base/worker/workerMain.js');`;
  return "data:text/javascript;charset=utf-8," + encodeURIComponent(workerCode);
};
```
