# 1 个remote 检查
## git remote -v
origin  https://gitee.com/null_562_1801/wys-json.git (fetch)
origin  https://gitee.com/null_562_1801/wys-json.git (push)

# 添加第二个remote 名字叫做 github
 git remote add github https://github.com/meiok1/wysjson.git


 # 分别推送两个仓库
 ```js
git push origin main
git push github main
 ```
